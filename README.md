Paradise Nursery

Project Name

Paradise Nursery Shopping Cart

Project Description

Paradise Nursery is a dynamic e-commerce web application for an online plant shop. The application allows users to browse different categories of houseplants, view plant information, add plants to a shopping cart, and manage their cart items.

Features

* Browse houseplants by category
* View plant thumbnails, names, descriptions, and prices
* Add plants to the shopping cart
* Dynamically update cart item quantities
* Increase or decrease plant quantities
* Remove plants from the cart
* Calculate the total cart price
* Responsive navigation bar
* Redux state management for the shopping cart

Technologies Used

* React.js
* Redux Toolkit
* JavaScript
* HTML
* CSS
* Vite

Project Purpose

The purpose of this project is to demonstrate the development of a functional and user-friendly e-commerce shopping cart application using React and Redux.
